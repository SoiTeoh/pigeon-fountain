# 坏鸽子抢喷泉（Pigeon Fountain）V2.0

一款基于 **Vite + TypeScript + HTML5 Canvas 2D + Web Audio API** 的竖屏街机物理喜剧小游戏（Idea Lab v2 — Project 02）。  
玩家扮演圆滚滚的坏黑鸽，在 4 大主题广场与无尽大乱斗中与倔强白胖鸽、跟屁虫小麻雀群及暴躁红冠鸽抢占喷泉水柱，利用「小跳墩坐」与「肥臀猛顶」把对手顶进红 `!` 暴走喷口或 `32°` 偏心斜喷泉，像愤怒的小鸟一样抛物线砸塌广场两侧喜剧道具！

## V2.0 Phase 1 核心玩法

- **4 大主题广场关卡 + 无尽大乱斗**：
  - **Stage 1 · 小区街角小喷泉**（目标 `350` 分，50s）：3 喷口 + 白胖鸽 + 纸杯塔/瓜子摊。
  - **Stage 2 · 公园中心音乐喷泉**（目标 `650` 分，50s）：4 喷口（双喷口 + `32°` 斜喷泉）+ 白鸽 & 2 只麻雀 + 大妈撒闪亮玉米粒（`+45` 分）。
  - **Stage 3 · 商业街网红地泉**（目标 `950` 分，50s）：4 喷口 + 白鸽 + 暴躁红冠鸽（`0.6s` 蓄力冲撞）+ 气球推车/网红咖啡杯架。
  - **Stage 4 · 市中心喷泉狂欢夜**（目标 `1300` 分，50s）：5 喷口波浪连环喷发 + 全员鸽雀大混战。
  - **无尽广场大乱斗**（60s）：难度波次递增，道具摧毁 `8s` 后自动补新，冲击本机最高分。
- **怒鸟式抛物线连锁破坏**：被高压暴走泉或 `32°` 斜喷泉炮弹轰飞的对手会按真实抛物线飞向两侧及高台道具，撞塌触发 `0.07s` 喜剧微顿帧（Hit-stop）与 `连锁爆破 +120！`（大妈瓜子摊还会额外爆出加分火花）。
- **眩晕硬直与「回气中...」**：`肥臀猛顶` 命中赋予对手 `0.60s` 眩晕滑行硬直（`> □ <`），冷却文案优化为 `回气中...` 搭配扇形恢复动画。
- **新动作「小跳墩坐 (`W`)」**（冷却 `0.9s`）：跃过对手或躲避红 `!` 暴喷，落回喷水中水柱核心区触发 `铁臀墩坐！+30` 与震荡波弹开周围对手。

## 操作方式（双拇指零冲突布局）

- **触屏 / 鼠标**：
  - **左下角**：`◀` / `▶` 方向按钮（同时兼容中上区左/右按住）。
  - **右下角**：`小跳 (W)` 与 `肥臀猛顶 (Space)` 圆形技能按钮。
  - **右上角**：`🔊` 静音与 `⏸` 暂停。
- **键盘**：`A` / `←` 向左，`D` / `→` 向右，`W` / `↑` 小跳，`Space` 肥臀猛顶，`Esc` / `P` 暂停，`R` 重开。
- **调试视图**：URL 后追加 `?debug=1` 可查看喷口核心区、水柱角度矢量、道具碰撞框、AI 硬直计时与红冠鸽蓄力线。

## 目录结构

- `src/platform/storage.ts`：轻量级存储接口层（Web `localStorage`，便于后续替换微信小游戏 `wx` 存储 API）
- `src/config/tuning.ts`：视口、4 关与无尽配置、3 种 AI 参数、喷泉状态机、双拇指按钮与道具参数
- `src/game/rules.ts`：纯 TypeScript 状态机、多喷口与斜喷/波浪调度、抛物线发射、墩坐与 AI 决策逻辑
- `src/game/world.ts`：确定性 2D 街机物理步进器、Hit-stop、道具碎裂与粒子/玉米拾取物
- `src/game/audio.ts`：零依赖 Web Audio API 合成音效
- `src/render/painter.ts`：全 Canvas 2D 绘制（4 主题广场、封面选关、暂停弹窗、星级结算与 `?debug=1` 叠层）
- `src/main.ts`：DPR 自适应、双拇指独立多指针管理与键盘控制
- `tests/rules.test.ts`：Vitest 单元测试（35 项）
